# 外设共享 0.10.5 验证记录

## 用户反馈与现场

0.10.2 双机正常使用反馈：跨屏双向停顿，返回后对端仍看见停留在边缘的箭头。只读快照中对端已为 `parked`，处于前台，隐藏/解绑 API 返回成功、无漂移或清理错误。这些状态不能推翻肉眼反馈，也不能当作隐藏已经生效。

两机同一路径的三次网络 RTT 为约 4.96–6.34 ms，平均 5.77 ms，仅作为该次网络样本；不是端到端交接延迟。

## 短时视觉验证

经用户逐次明确同意，独立临时工具仅改变本机焦点与光标外观，不创建输入 tap、不解绑、不 warp、不注入键鼠、不录屏、不修改共享设置或重启生产应用。

前两次在实际隐藏阶段前退出：一次没有取得前台；一次将约 1.5 点的移动过严地判为取消。不作为有效视觉测试。

最后一次改为用户主动点击开始，松开鼠标后倒计时，再比较 A/B/C。工具完整结束，用户确认：

- A：`CGDisplayHideCursor` 系统隐藏真正有效。
- B：透明 `NSCursor` 未达到肉眼完全隐藏。
- C：后台微型窗口与透明光标未达到肉眼完全隐藏。
- 结束后光标和原应用焦点均恢复正常。

B 阶段系统 cursor-image alpha 已为零，但用户仍看到箭头，说明该 API 元数据同样不能代替真实显示验证。生产不采用 B/C。所有临时工具已退出，不保留继续操作光标的授权。

## 实现变更

- 继续使用公开系统隐藏与既有资源租约。激活路径等待 LaunchServices 最后请求完成、捕获窗口确为 key window，并经过一次稳定主线程调度；不再仅以刚改变的前台 PID 提前隐藏，不重复累加 hide 计数。
- 锚点在解绑/隐藏成功后采样，之后仍执行原有 0.5 点漂移检查、前台、tap、未过期租约与独立监护，不弱化转发资格。
- 源端取得捕获资格与对端恢复/准备接收并行；源端有资格但尚未提交时为 `staged`，不能发送网络输入。只有双方准备、同一 handoff ID、源端租约有效并提交后才开始转发。
- 准备期间只合并一个鼠标位移向量，每轴最多 4096。键盘、按钮或滚轮取消交接，按原来的有界本机恢复路径，在原应用焦点验证后回放，不向尚未就绪的对端发键。
- 新一次切焦点前也排空已经提交的本机恢复事件，避免快速交接把旧本机回放送进捕获窗口。接收回放最多 512 项、清理释放最多 288 项、本机恢复元数据最多 128 项；排空最多 250 ms。
- 正常接收和确认返回移除统一 650 ms 等待；真正的反向运动可立即返回。失败、拒绝与急停仍退避，且方向/几何、按住状态和重复请求保护保留。
- 私有汇总增加激活、取得租约和排空回放的实际耗时，不记录按键内容或轨迹。

没有新增空闲轮询；激活等待仍有界，准备阶段沿用原有会话截止与租约监护。尚未测量本版本真实双机端到端延迟、footprint、CPU/GPU 和多轮增长，不宣称性能验收。

## 自动回归

冻结源码后 **108 项 / 5 组相关串行测试通过**，其中 53 项为注入 CG/焦点后端的光标生命周期测试；不是全量回归或 Xcode target 编译。

覆盖：激活回复前已有前台仍不可隐藏、key window/焦点变化、租约锚点、并行准备与提交门、准备期间移动合并、键入取消及迟到焦点恢复、真实本机恢复排空、快速反向、失败退避、陈旧输入和释放、协议兼容、像素布局及身份迁移。

一次广范围运行暴露测试夹具的随机布局方向：UUID 布局 stamp 可能选择任一镜像方向，固定向右的假鼠标动作会变成真实反向返回。夹具显式同步右/左布局并等待 ACK 后复验通过，没有修改生产几何以迁就测试。

用户明确选择更新两台。检查发现，本机已经运行的正式 **0.10.5 / build 34** 构建包含相同的三份共享实现、协议和本次测试源码；对应原始构建快照与候选逐字节一致。因此复用这个签名构建，而非用较旧基底覆盖当前语音更新，也未混入工作区后续语音 WIP。

- 两端均为 **0.10.5 / build 34**，外设共享经原生导入为 **1.4.2 / minimumHostVersion 0.10.5**。
- 固定 Developer ID 团队 `LQ97GA8LY8`、Hardened Runtime、时间戳、深层签名及指定要求核对通过；两端 CDHash 同为 `65873ce8e6801c1400cd784e7c1ee09e3073814d`。
- 远端正常退出后替换；本机仅正常退出/重开和导入共享插件，跳过相同二进制替换，保留现有语音 1.1.4。没有强制退出、安装 HAL、重启音频服务、读取 Keychain 内容或改变语音偏好。
- 已私有备份应用归档、偏好及应用支持目录；归档解压验签后移除临时可运行旧副本。配对访问身份、deviceID、保存地址、开启意图和像素布局语义保留，本机原有 4 个插件/12 条命令和远端 1 个插件/0 条命令保留，未重建用户已删除的默认命令。
- 更新后只读确认两端互为对端、布局 ACK 就绪、键鼠/tap 有效；当时两端均为 `local`，无隐藏/解绑资源、无恢复或队列积压，共享音频关闭，收发输入计数为零。更新后没有主动进行键鼠、焦点或光标探针。
