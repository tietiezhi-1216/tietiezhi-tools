# 全局快捷键

v1.2.2 需要 Untitled 0.10.0+，采用通用界面槽位协议，并声明无需系统隐私权限。

从 Untitled 首页安装后，在侧边栏打开本插件，点击“添加操作”。

- **打开应用**：选择本机 `.app`，已运行时切到前台。
- **打开网址**：使用默认浏览器打开 HTTP / HTTPS 网址。
- **运行快捷指令**：填写 macOS「快捷指令」中已有指令的名称。
- **显示主面板**：将 Untitled 主窗口带到前台；关闭后可重新打开。

点击录制按钮，然后按下包含 `⌘`、`⌥` 或 `⌃` 的组合键。也可以不绑定快捷键，仅使用播放按钮执行。系统或其他应用占用的组合键会提示注册失败，需重新选择。

主窗口关闭后应用仍在菜单栏运行，快捷键继续有效；退出应用后全部快捷键停止。第一版不自动设置登录启动，也不会替换系统快捷键。

这个插件采用声明格式，不包含原生二进制或任意 Shell 脚本。需要更复杂的操作时，可以调用你自己配置的 macOS 快捷指令。

## 性能与资源

本插件只注册 Carbon 热键并响应用户操作，没有自己的轮询、媒体缓存或常驻计算任务。外部应用和系统快捷指令的消耗需与宿主分开观察。开发时按[性能规范](../../docs/PERFORMANCE.md)比较停用、启用空闲、反复触发和停用后的占用，确认重复配置不累积热键或观察者。

当前热键冲突、停用释放与配置升级已有自动测试；插件自身的 footprint、空闲 CPU 和多轮触发后峰值尚未采样，不宣称零开销。
