# 截图

v1.2.0 需要 Tietiezhi Tools 0.5.0+；录屏和系统翻译需要 macOS 15+。
在商店安装本插件，在「快捷键」中添加截图、贴图、滚动截图或录屏操作并录制全局组合键。安装时不会自动占用任何快捷键。

## 使用

- **截图**：区域、窗口、鼠标所在屏幕的全屏截图；支持多显示器与 Retina 原始分辨率。拖动选择区域，窗口截图可点击窗口；Esc 或右键取消。
- **编辑**：箭头、矩形、椭圆、直线、自由画笔、荧光笔、文字/水印、序号、马赛克、实色遮挡、背景擦除、放大镜、裁剪和旋转。支持撤销、重做、缩放、取色；复制和 PNG/JPEG/PDF 导出使用实际处理后的像素，并保留原图 RGB 色彩空间。背景擦除使用边缘颜色插值，适合单色或渐变背景，不生成复杂纹理。
- **贴图**：截图或剪贴板图片/文字置顶显示。拖动移动，滚轮或触控板捏合缩放，右键复制、编辑、保存、调整透明度，双击关闭；全局操作可隐藏/恢复全部贴图。
- **长截图**：选择纵向或横向，框定内容区域，缓慢滚动，保持至少三分之一重叠。程序检测重叠后拼接，支持反向回滚和多个方向的显示器。自动滚动需要辅助功能权限。无法匹配时不会盲目拼图；动态动画、无纹理背景、固定的大面积页头可能影响结果。
- **录屏**：框选区域录制 H.264 MP4（30 fps、最长边最高 4096），按需包含系统音频、麦克风、鼠标点击、摄像头画中画和键盘按键。画中画可移动和缩放；键盘显示仅在录屏期间启用，安全输入时暂停。再次触发同一快捷键或点击浮动控制条停止。历史中播放、选择起止时间、导出裁剪 MP4 或 GIF（10 fps、最长 3 分钟、最长边 1280）。导出成功前不替换目标文件。
- **识别与翻译**：编辑器中的「识别 / 翻译」使用 Apple Vision 本地 OCR 和条码识别；系统翻译首次可能要求下载语言模型。可修改原文与结果，复制或导出。
- **表格、公式、文档**：本地文字位置可生成基础表格并导出 CSV/XLSX；macOS 26+ 可使用系统的本地文档结构识别。复杂表格、LaTeX 公式、保留层次的 Markdown 文档和图片翻译可调用自行配置的视觉模型。结果可编辑，并可导出 TXT/Markdown/LaTeX/Word（DOCX）和可搜索文本 PDF；Word 支持标题、段落与基础 Markdown 表格。编辑器另可将图片直接导出为 PDF 页面。

## 权限与数据

系统授权统一位于主应用「应用设置 → 权限管理」。截图或录屏缺少权限时，由主应用说明用途并提供授权入口；点击授权后才出现 macOS 系统请求。授权后请重新执行，部分系统权限更改可能需要重启应用。

麦克风、画中画和按键显示是本插件的业务选项；仅在实际录制且对应选项开启时，向宿主请求麦克风、摄像头或输入监控。自动滚动实际开启时请求辅助功能，手动滚动不需要。这些录制扩展默认关闭。插件不再提供独立授权按钮或系统设置跳转。

历史记录位于 Application Support/com.tietiezhi.tools/Capture，默认保存在本机，可逐项移到废纸篓。插件禁用会取消选区、关闭贴图并结束录屏；历史不会在卸载插件时删除。不要把自己的截图或 API 密钥提交到仓库。

顶部齿轮打开本插件的「截图设置」，包括滚动方向、录屏选项和视觉模型配置。应用外观设置位于侧边栏底部。

视觉模型设置位于本插件「截图设置」，填写 HTTPS Chat Completions 接口、支持图像的模型名和 API 密钥；密钥保存在 macOS 钥匙串。每次发送前会要求确认图片和目的服务，服务可能产生费用。没有配置时本地 OCR、表格布局提取和系统翻译仍可使用；公式/复杂文档识别需要配置服务。

## 当前边界

这是原生 macOS 实现，参考 [PixPin 官方功能](https://pixpin.cn/features/)，不复用 PixPin 私有服务。未提供 PixPin 账号、会员服务、生成式 AI 智能擦除、WebP 动画或自由多边形选区；复杂表格、公式和文档的准确性取决于配置的视觉模型，需要校对。GIF 不含声音；Word 导出包含可编辑文本和基础结构，复杂排版不会按像素还原。此版本不宣称与 PixPin 全部功能一比一等价。

开发构建采用临时签名，尚未使用 Developer ID 签名与公证。可从项目源码执行构建脚本使用。
