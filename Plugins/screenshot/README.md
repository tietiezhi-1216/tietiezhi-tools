# 截图

v1.5.0 需要 Untitled 0.9.0+；录屏和系统翻译需要 macOS 15+。
首次安装自动配置 [PixPin macOS 默认快捷键](https://pixpin.cn/docs/settings/shortcuts-actions)：

| 动作 | 默认快捷键 |
| --- | --- |
| 区域截图 | ⌃1 |
| 延时截图 | ⌥1 |
| 截图并复制 | ⌃⌥1 |
| 剪贴板贴图 | ⌃2 |
| 恢复最后关闭的贴图 | ⌃3 |
| 切换贴图组 | ⌃` |

⌃ 表示 Control。升级保留已有操作的自定义按键、清空、停用状态；后续升级不会恢复已删除的默认动作。与其他操作冲突时保留对方的绑定，新动作留空。可在「快捷键」页添加其他操作、暂停截图快捷键或恢复默认。恢复默认会重设默认动作，但保留自行添加的其他操作。系统注册冲突会在操作旁显示，若同时运行 PixPin，请先释放对应组合键。

[编辑及贴图窗口快捷键](https://pixpin.cn/docs/settings/built-in-shortcuts)同样采用 PixPin 的 macOS 默认值，可在齿轮设置中展开「编辑与贴图快捷键」修改。包括 Return 完成并复制、⌘Y 重做、⇧⌘Z 清除标注、⇧C OCR 并复制、⌥Q 翻译、⇧1–⇧0 标注工具、⌘E 选择标注；文本输入时保留正常编辑按键。

## 使用

### 截图与选区

区域、窗口、鼠标所在屏幕的全屏截图；支持多显示器与 Retina。普通截图可跨屏框选，⌘A 先选择鼠标所在屏，再按一次选择全部屏幕。选区栏提供矩形、自由轮廓、折线和多窗口模式，并可增加或扣除区域；不规则选区的外部区域为透明像素。

拖动框选后，可继续移动选区、拖动边角调整大小，或输入 X/Y/宽/高像素值。支持固定比例、⇧ 正方形／水平垂直约束、⌥ 对称调整、方向键微移、⌘方向键扩大及 ⇧方向键收缩。窗口检测可直接选中窗口；已获辅助功能权限时可用 Tab 切换界面元素检测。⌥ 显示放大镜与辅助线，C 复制颜色，⌥C 复制坐标，F5 刷新画面。

选区栏可直接点击箭头、矩形、马赛克或文字进入标注，也可直接复制、贴图、保存；双击选区、回车或「编辑」进入默认拖动工具。截图可加圆角、阴影或边框，「样式」中可调整圆角半径、阴影模糊／浓度／偏移、边框宽度与颜色，并选择以后截图沿用这些效果。单屏选区的矩形范围保留最近 100 条，可从「历史选区」恢复；历史范围不恢复自由轮廓或扣除蒙版，跨屏范围不写入单屏历史。录屏、长截图使用单屏矩形选区。

确认后在原位置显示无边框编辑浮层，工具条随图片移动并避开屏幕边缘。截图保留当前可见的主窗口与贴图，只排除截图控制浮层；切换工具后可直接开始第一笔标注。延时截图支持 1–60 秒可取消倒计时。重复上次区域会检查原显示器是否连接并裁切到有效范围。

### 编辑与标注

默认手形工具用于拖动图片，标注模式中可用 ⌥ 临时拖动。工具条按当前工具显示样式；画完自动选中，端点、缩放、圆角和曲线控制点直接显示在图上。选中后按 Delete 删除、方向键微调（⇧ 为 10 像素）；⌘滚轮调整透明度。Esc 先退出当前绘制／选择，再关闭浮层。编辑状态下 Return 完成并复制。常用工具可拖动排序，移到「更多工具」或重新加入。

| 工具 | 当前实现 |
| --- | --- |
| 矩形／椭圆 | 轮廓、半透明／实心填充、实线／虚线／点线／点划线；圆角数值与控制点、缩放及旋转；⇧ 保持正方形／圆形；圆环、扇形、环形扇形 |
| 箭头 | 线条、实心、渐宽实心、渐宽轮廓、双向、尺寸线；拖中间圆点拉成曲线、拖端点改方向；右键中点恢复直线；说明文字可独立移动 |
| 序号 | 连续生成编号，圆形／空心／圆角方形／纯数字，数字／补零／字母／罗马数字；手动改号、重置、引导箭头与说明、删除后连续补号；设置中可开启跨截图连续计数 |
| 直线／折线 | 线型；折线连续点击加节点，双击或右键完成；⇧ 对齐 45°；节点可再次拖动 |
| 画笔／荧光笔 | 平滑笔迹、颜色、粗细、透明度；可选择移动与删除 |
| 马赛克 | 矩形或自由画笔；像素马赛克、模糊、实色遮挡；分别设置强度与画笔范围；矩形圆角和覆盖范围可再编辑 |
| 文字 | 本机字体、字号、粗体、斜体、描边、背景、换行宽度、颜色与透明度；双击重新输入 |
| 橡皮擦 | ⇧9 擦除标注，不破坏底图 |
| 纹理修补 | 从周围图像匹配纹理修复选中区域；无需模型，不等同于生成式擦除 |
| 智能擦除 | 可选 LaMa Core ML 模型，生成选区内的替代内容；完全本地执行，支持撤销 |
| 聚光灯 | 矩形／椭圆重点区域、可调周围暗度 |
| 放大镜 | 原位或旁置放大、圆形／矩形、倍率；旁置模式有源区域与连线，可拖动放大图中心 |
| 水印 | 单个或平铺，字号、角度、透明度；支持 `{date}` / `{time}`，时间在创建时固定 |
| 自动马赛克 | 本地 OCR、人脸与条码检测，匹配手机号、邮箱、身份证、密码字段、网址、IPv4；预览后勾选目标，支持相同文字／条码及相似人脸图块联动选择 |

右键已有标注可复制、置顶、置底或删除。预览和导出使用同一套渲染；马赛克写入实际输出像素。自动检测可能漏选或误选，分享前应检查结果。相似图块关联不代表能识别人物身份。

复制、保存、关闭和退出应用时，历史中的底图与标注会保留，重新打开可继续修改。裁剪、整体旋转和修补会将当时的标注合并到图像；当前编辑会话仍可撤销，关闭后不保留完整撤销栈。

### 贴图

- **内容**：图片、纯文本、保留本地格式的 HTML 文本、颜色值、LaTeX 公式、文件卡片和系统支持的 GIF/APNG/WebP 动图。公式以随应用打包的 KaTeX 在本机渲染；复制 LaTeX 源码并贴图即可使用，不需要视觉模型。非图片文件显示文件名与图标，右键可在访达中定位源文件。
- **操作**：移动、滚轮／捏合缩放、透明度、锁定、置顶、阴影、鼠标穿透、分组、关闭后恢复、隐藏其他贴图、逐像素移动。支持多选后的批量关闭、恢复、移动到分组。图片可旋转、翻转、黑白、反色及调整亮度。
- **选字与拖出**：图片自动检测文字后可直接选中并复制；文本贴图可选字。⌥拖动忽略文字选择，⌘拖动把内容拖入其他应用。图片文字选择使用本地 OCR，识别顺序与准确性受图片内容影响。
- **缩略图和动图**：缩略图模式仅显示选定的一部分，可移动查看范围；动图支持播放／暂停、逐帧查看、调整速度。原始动图文件单独保存在本机，播放控制不改变原文件。
- **鼠标配置**：默认双击关闭、中键重置、⇧双击切换缩略图、⌘滚轮调整透明度；可在「贴图鼠标操作」中修改缩放、关闭、复制、拖出、多选等绑定。

「贴图」页管理分组与关闭历史。图像、位置和状态保存在本机，重启后恢复未关闭的贴图；删除文件卡片不会删除源文件。HTML 仅保留本地排版，不加载外部图片、脚本或远程样式。

### 长截图

选择纵向或横向，框定单屏内容区域，缓慢滚动，保留至少三分之一重叠。支持反向回滚、自动滚动、实时拼接预览、暂停／继续、重新开始、起止范围裁剪，以及「回滚时裁掉多余部分」。自动滚动需要辅助功能权限，手动滚动不需要。

无法匹配时不会盲目拼图；可回到最后成功拼接的位置继续。动态动画、无纹理背景、固定的大面积页头仍可能影响结果。横纵方向分别拼接，不是同时进行二维全景拼接。

单段达到 8000 万像素前会自动将当前段写入磁盘，再从上一视口继续下一段，保留接缝重叠，不再继续增大内存中的长图。面板显示当前分段编号；「分段导出」也可主动保存短图。完成后选择文件夹，导出按上到下／左到右编号的 PNG、`segments.json` 坐标与重叠索引以及阅读顺序说明。已封存段不接受回滚修改；起点／终点裁剪只作用于当前段。取消目录选择会保留暂停状态，导出失败可重试。「保留并关闭」或退出应用前会暂存当前段，可由「暂存目录」找回 PNG 和索引；成功导出后也保留暂存副本。

### 录屏与动图导出

macOS 15+ 可将单屏矩形区域录制为 H.264 MP4；帧率可选 5／16／24／30／60 fps，最长边可选 1280／1920／2560／4096。支持倒计时、暂停／继续、停止和重新录制。暂停通过分段记录并合并处理，暂停时间不进入最终视频。

可分别录制系统音频和麦克风，选择摄像头画中画（最多两台不同设备），记录鼠标及键盘事件。摄像头可移动、调整形状和大小。键盘记录仅在录屏期间启用，系统安全输入期间暂停。键鼠事件与音轨另存，回放时可修改效果及音量。

录制中可使用箭头、矩形、椭圆、序号、画笔及荧光笔，调整颜色与线宽，撤销或清空标注。默认鼠标操作穿透到被录制应用，选择工具后才进入绘制，右键可恢复屏幕操作；这些标注会写入视频画面。

回放支持起止时间裁剪、画面裁剪、0.2–2 倍速、画质、系统音频／麦克风音量，以及光标、点击和按键效果。可导出 MP4、GIF 或 WebP；动图帧率及尺寸可调，按倍速计算的结果最长 3 分钟，GIF/WebP 不包含声音。WebP 编码器随签名应用打包，用户无需另装命令行工具。

应用启动时可恢复意外中断前已经封存的录屏片段；最后尚未写完的片段不能保证恢复。正常退出应用会结束并保存录屏。导出成功前不替换目标文件。

### 识别、翻译、表格与文档

「识别／翻译」使用 Apple Vision 本地 OCR 和条码识别。系统翻译需要 macOS 15+，首次使用某语言可能需要下载系统语言模型。可编辑原文与译文，复制或导出；图片翻译按 OCR 文字行把译文放回对应位置。长译文无法容纳时会提示并保留文字结果，复杂背景及排版不保证还原。

表格预览先从本地 OCR 的文字位置生成基础结构，并在原图旁显示单元格位置。macOS 26+ 可手动「重新识别结构」，使用系统本地模型识别多个表格和合并单元格；识别期间可取消，未识别出表格时保留基础结果。可修改文本、合并／拆分单元格，并导出保留表格结构的 XLSX 或 DOCX。另支持 CSV、TXT、Markdown、LaTeX，以及原图附带可搜索文字层的 PDF；编辑器也可直接将图像导出为 PDF 页面。

公式识别、复杂内容的进一步识别可使用自行配置的视觉模型。未配置时，不提供本地数学公式转 LaTeX 的识别能力；已有 LaTeX 源码的贴图渲染仍可使用。Word 导出保留可编辑文本、标题和表格结构，不按像素还原复杂文档。

### 保存与全局鼠标

在「截图设置」中选择快速保存目录、格式、有损质量与文件名模板。支持 `{date}`、`{time}`、`{width}`、`{height}`、`{uuid}`；同名文件自动增加编号。可开启复制截图或贴图时自动导出。除随包编码器支持的 WebP 外，格式列表按当前系统 ImageIO 的编码能力显示，PNG 使用无损编码。静态 WebP 可调整有损质量，宽高各不超过 16383 像素；更大的图片可保存为 PNG／TIFF。

导出保留规则默认关闭；启用后仅清理本应用在目标目录中追踪且 SHA-256 未变化的旧导出文件，将其移到废纸篓，已修改或替换的文件会保留。导出文件与应用内部截图历史分别管理。

全局鼠标默认关闭。可添加多组「修饰键＋左／右／中键／侧键拖动」，每组独立启停，松开后编辑、复制、贴图、OCR 复制或快速保存。相同组合不能同时绑定两个启用的动作；已有单组设置会自动保留为第一组。未匹配的输入正常传递，点击或未形成有效截图的短拖动会还原为普通点击。忽略应用按 bundle ID 匹配，支持 `*`；所需权限仍由主应用管理。暂停截图快捷键或停用插件时，该入口也暂停。

## 权限与数据

系统授权统一位于主应用「应用设置 → 权限管理」。截图或录屏缺少权限时，由主应用说明用途并提供授权入口；点击授权后才出现 macOS 系统请求。授权后请重新执行，部分系统权限更改可能需要重启应用。

麦克风、画中画和按键显示是本插件的业务选项；仅在实际录制且对应选项开启时，向宿主请求麦克风、摄像头或输入监控。自动滚动或全局鼠标需要辅助功能，手动滚动不需要；元素检测仅使用已经获得的辅助功能权限。录制扩展和全局鼠标默认关闭。权限请求由插件交给宿主，系统授权入口保持集中。

历史记录位于 Application Support/com.tietiezhi.tools/Capture，默认保存在本机，可逐项移到废纸篓。`.editing` 文件保存原始底图和标注，供以后再次编辑；这些源文件仅保存在本机。复制和导出的 PNG/JPEG/PDF 只包含渲染后的结果，不携带该源文件。插件禁用会取消选区、关闭贴图并结束录屏；历史不会在卸载插件时删除。不要把自己的截图或 API 密钥提交到仓库。

顶部齿轮打开本插件的「截图设置」，包括窗口内快捷键、贴图鼠标操作、保存规则、全局鼠标、滚动方向、录屏选项、本地擦除模型及视觉模型服务配置。应用外观设置位于侧边栏底部。

视觉模型设置位于本插件「截图设置」，填写 HTTPS Chat Completions 接口、支持图像的模型名和 API 密钥；密钥保存在 macOS 钥匙串。每次发送前会要求确认图片和目的服务，服务可能产生费用。没有配置时本地 OCR、文档结构提取、系统翻译和本地译图仍可使用；数学公式识别需要配置服务。

「本地智能擦除」单独提供 [LaMa Core ML](https://huggingface.co/mlboydaisuke/LaMa-CoreML) 的下载与移除入口。用户点击后才下载 187 MiB 模型，安装前校验固定版本的 SHA-256，并在本机编译、缓存。模型及 Apache-2.0 许可位于 `Capture/Models`；图片不上传。本地模型未安装时，纹理修补仍可使用。模型权重不包含在插件 ZIP 或主应用包内。

## 性能与资源

高开销路径包括大图解码与标注、长图拼接、贴图与动图、录屏回放和转码、Vision 识别及可选 Core ML 模型。压缩图片和模型下载大小不等于运行内存。单图上限为 8000 万像素，单份 RGBA 数据就约 305 MiB，掩码、撤销副本和中间结果还会增加峰值。

超长滚动图将封存分段写入磁盘，继续维护活动分段，不将所有段合并为无限大的内存图。分段暂存和历史仍会占用磁盘；需按实际工作流清理保留内容。WebP helper 的消耗与宿主分开观察，贴图数量、动图帧数、并行识别与导出也需计入负载。

按[性能规范](../../docs/PERFORMANCE.md)分别测试普通图片、接近像素上限的大图、跨分段长图、持续录屏、动图导出、多贴图和模型冷 / 暖启动。记录基线、峰值、CPU / GPU、耗时、取消及停用后的状态，并重复启停观察资源趋势。分段边界、容量拒绝和媒体处理已有功能测试；真实 4K 长时间录制、模型、GPU 与多工作流并发的整机性能峰值尚未完成剖析，不将这些测试视为完整性能验收。

## 当前边界

这是依据[公开功能文档](https://pixpin.cn/docs)独立实现的原生 macOS 插件，并非 PixPin 源码的 fork，不包含 PixPin 账号、会员或私有服务。主要截图、标注、贴图、长图、录屏和识别流程已有对应实现，仍不宣称每项偏好、鼠标组合、视觉效果或算法质量与 PixPin 一比一相同。

- 单张图片编辑仍受 8000 万像素上限约束；超长滚动截图使用磁盘分段导出，不会合并为无限大的单张图片。分段间保留重叠，已封存部分不可回滚裁剪。
- 尚未提供兼容 PixPin 的 JavaScript 自定义动作运行时或命令行接口；插件功能通过本项目的原生开发协议注册。
- 本地 OCR、表格和图片译文定位可能识别或排版错误；复杂背景的译图采用周边颜色覆盖，不会精确重建背景。公式识别需要配置模型服务，Word 不保证原文档像素级排版。
